# 地区自动选择与 arXiv

地区组只收纳高速来源节点，排除家宽、Extra 和通知。名称和明确的地区代码元数据共用一个分类器：显式元数据优先，名称有多个地区时采用第一个标记。美国自动组和美国地区组使用相同分类结果。

所有地区组使用 `url-test`，每 300 秒检查一次，切换容差 100ms。默认代理提供跨地区故障转移、自动选择和各地区组，避免默认出口只依赖美国。

个人偏好在 `preferredNodesByRegion` 中按地区代码填写节点名称；原名和自动消歧后的同名节点都能匹配，失效偏好不会生成不存在的节点。不要把个人节点名称写入公共 INI。

`📄 arXiv` 默认香港自动组，可独立选择日本、美国、其他地区或默认代理。缺少某地区节点时省略空组及引用，按 INI 继续选择其他可用项。保留一个地区选择并不意味着地区间始终自动切换；需要跨地区自动容灾时，选择默认代理或通用故障转移。

测试：`node tests/test_region_routing.mjs`，完整验证：`node scripts/validate.mjs`。
